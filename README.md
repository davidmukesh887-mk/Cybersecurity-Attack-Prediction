Cybersecurity Attack Prediction

A Cybersecurity Attack Detection and Prediction project using Python, SQL, and Power BI.

Project Overview

This project analyzes cybersecurity attack data and compares actual attack types with predicted attack types to evaluate prediction performance.

Tools & Technologies

- Python – Data analysis and prediction
- SQL – Data storage and analysis
- Power BI – Interactive dashboard visualization

Dataset

- Dataset: Cybersecurity_Predictions
- Total Records: 122,159

Project Results

- Correct Predictions: 121,651
- Incorrect Predictions: 508
- Model Accuracy: 99.58%

Dashboard

The Power BI dashboard displays:

- Correct and Incorrect Predictions
- Total Predictions
- Model Accuracy
- Prediction Status Distribution
- Cybersecurity Attack Types
- Interactive Filters
